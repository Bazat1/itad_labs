# Отчёт о качестве: OWID Energy

## 1. Контекст

Вопрос из `Project Brief`: Как изменяется углеродоёмкость электроэнергии в европейских странах с разным преобладающим источником генерации с 2000 по 2025 год?

Гранулярность: одна строка описывает одну страну за один год.  

Ключ дедупликации: бизнес-ключ - комбинация `country + year`.

Входной файл:

```text
s3://raw/owid_energy/ingested_on=2026-10-02/owid-energy-data.csv
```

Логическая дата загрузки - `2026-10-02`, аналитический период - 2000–2025 по полю year.

## 2. Профиль

В исходном наборе **23 377 строк и 130 поле**. При чтении S3-пути DuckDB автоматически добавляет техническое поле `ingested_on`, поэтому ноутбук может показывать больше полей. Для задачи выбраны ключевые аналитические поля. Для каждого проверены все 23 377 строк:

| Поле                    | Тип      | Примеры значений               | Пропуски / доля |
|-------------------------|----------|--------------------------------|-----------------|
| `country`               | `VARCHAR`| `ASEAN (Ember)`, `Afghanistan` | 0 / 0 %         |
| `year`                  | `BIGINT` | `1900`, `2023`                 | 0 / 0 %         |
| `carbon_intensity_elec` | `DOUBLE` | `0.0`, `17.24`                 | 17 045 / 72.9 % |
| `renewables_share_elec` | `DOUBLE` | `0.0`, `0.004`                 | 15 505 / 66.3 % |
| `coal_share_elec`       | `DOUBLE` | `0.0`, `0.017`                 | 16 235 / 69.4 % |

Полных дубликатов — 0. Количество дубликатов считается как `count(*)` минус количество строк после `SELECT DISTINCT` по всем исходным полям. Проверка бизнес-ключа `country + year` также показала 0 повторов.
Фактический период в данных: `1900` – `2025`.

Распределение по годам (фрагмент, демонстрирующий неполноту последних лет):

| Год  | Записей |
|------|---------|
| 2022 | 293     |
| 2023 | 293     |
| 2024 | 254     |
| 2025 | 106     |

**Значимые наблюдения:**
- **Структурные пропуски:** 66–73% пропусков по метрикам связаны с тем, что OWID включает данные по всему миру, включая регионы-агрегаты и страны, где электроэнергетика не развита или отсутствует отчётность.
- **Неполнота 2025 года:** Резкое падение числа записей в 2024–2025 гг. (до 254 и 106 соответственно) означает, что данные за последний год предварительные. Анализ динамики строго до 2025 года может привести к ложным выводам о падении показателей из-за отсутствия части стран в датасете.

Примеры критических нарушений из ноутбука:

| Страна | Год | Углеродоёмкость | Решение |
| :--- | :--- | :--- | :--- |
| `Afganistan` | 1900 | `NULL` | Карантин: год вне периода 2000-2025. |
| `Albania` | 1900 | `NULL` | Карантин: год вне периода 2000-2025. |

## 4. Подготовленные данные

Выходные пути на S3:

```text
s3://staging/owid_energy/source_ingested_on=2026-10-02/staging.parquet
s3://staging/owid_energy/source_ingested_on=2026-10-02/quarantine.parquet
```

В staging добавлен признак `quality_carbon_intensity_missing`: `true` — углеродоёмкость отсутствует (но строка валидна по другим параметрам), `false` — значение присутствует.

Техническое поле `ingested_on` также сохраняется в обоих результатах. 

Карантин сохраняет исходные поля, `quality_rule_ids` со списком критических причин через `;` и читаемый
`quarantine_reason`. При нескольких причинах запись сохраняется один раз.

Баланс строк: **23 377** = **7636 + 15741**. 

После чтения записанных результатов критических нарушений в staging — 0. Все строки с отсутствующей углеродоёмкостью корректно помечены флагом `True`.
